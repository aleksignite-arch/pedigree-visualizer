Визуализатор родословной (Pedigree Visualizer)

Пользователь строит родословную в интерактивном интерфейсе:
Добавляет людей (мужчина — квадрат, женщина — круг) 
Указывает, болен человек или здоров
Соединяет супругов линией брака
Добавляет детей к парам
После построения инструмент автоматически анализирует родословную и выдаёт:
«Тип наследования: _____»
«Обоснование: ____»
«Генотипы: Пробанд — __, родители — __ × __»
Модель предметной области:
Person (Человек)
  - id: str
  - name: str
  - sex: 'M' | 'F'
  - affected: bool (болен/здоров)
  - deceased: bool
  - notes: str
Family (Семья)
  - id: str
  - parent1_id: str (Person.id)
  - parent2_id: str (Person.id)
  - children_ids: list[str]
Pedigree (Родословная)
  - id: str
  - name: str
  - persons: dict[str, Person]
  - families: list[Family]
  -proband_id: str (с кого начинается анализ)
InheritanceAnalysis (Анализ наследования)
  - pedigree_id: str
  - possible_modes: list[InheritanceMode]
  - best_mode: InheritanceMode
  - evidence: list[str]
  - genotypes: dict[person_id, str]

InheritanceMode (Тип наследования) — enum
  - AUTOSOMAL_DOMINANT
  - AUTOSOMAL_RECESSIVE
  - X_LINKED_DOMINANT
  - X_LINKED_RECESSIVE
  - Y_LINKED
  - MITOCHONDRIAL
Правила анализа наследования (ядро проекта)
Реализуется набор правил, которые проверяют родословную и исключают неподходящие типы. Например:
Аутосомно-доминантный:
•	Признак встречается в каждом поколении
•	У больного родителя есть больной ребёнок
•	Мужчины и женщины болеют с одинаковой частотой
Аутосомно-рецессивный:
•	Признак может обнаружиться через поколение
•	У двух здоровых родителей может быть больной ребёнок
•	Мужчины и женщины болеют одинаково часто
X-сцепленный рецессивный:
•	Болеют преимущественно мужчины
•	У больного отца все дочери — носительницы, но здоровы
•	У здоровых родителей может быть больной сын
Y-сцепленный:
•	Болеют только мужчины
•	Передаётся от отца ко всем сыновьям
•	Женщины не болеют и не передают
Логика реализации: для каждого типа наследования - функция check_autosomal_recessive(pedigree) -> bool, которая возвращает True, если родословная не противоречит этому типу. Если подходит только один — это ответ. Если несколько — выводятся все возможные с обоснованием.

Архитектура проекта:
Интерфейс (Streamlit)	
Самый быстрый способ сделать интерактивный редактор. Кнопки «добавить человека», «добавить ребёнка», «выбрать больного»
Граф (NetworkX)
Построение дерева связей, поиск поколений, обход графа.
Визуализация (Matplotlib или Graphviz)
Рисование символов (квадраты/круги), линий брака и детей.
Хранение данных (SQLite или JSON)
Для сохранения построенных родословных.
Логика анализа (Python)
Условия и циклы, никаких библиотек.
